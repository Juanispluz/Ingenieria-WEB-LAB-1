El hotel

El Hotel Las Palmas es un hotel familiar que lleva varios años atendiendo viajeros de paso y turistas. La idea de este sitio es que el huésped pueda dejar sus datos y pedir una reserva sin tener que llamar por teléfono.

Sobre este proyecto

Este sitio es la práctica evaluativa del 20 % de la asignatura Ingeniería Web. La temática asignada fue Hotel. El servidor está hecho solamente con módulos que ya trae Node.js, sin instalar paquetes externos.

La información se guarda en una base de datos SQLite llamada hotel.db, que tiene dos tablas: una para los huéspedes y otra para las reservas.
