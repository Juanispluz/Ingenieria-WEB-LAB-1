Bienvenido

El Hotel Las Palmas es un hotel pequeño de 30 habitaciones pensado para viajeros que buscan tranquilidad. Contamos con desayuno incluido, wifi en todas las habitaciones y atención en recepción las 24 horas.

Desde este sitio usted puede registrarse como huésped y después solicitar una reserva usando el número que le entrega el sistema.

Nuestras habitaciones

  • Sencilla: una cama, ideal para viaje de trabajo.
  • Doble: dos camas, para parejas o amigos.
  • Familiar: hasta cuatro personas, con sala pequeña.

¿Cómo pedir una reserva?

Primero debe registrarse en la página Registro. Al terminar el sistema le muestra un número de huésped. Ese número se pide más adelante en la página Servicios para guardar la reserva.
